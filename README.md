# Ai-language-tutor
# Simple English to Hindi Language Tutor

This is a simple command-line application that helps users translate English sentences to Hindi, practice vocabulary, and take quizzes to test their knowledge. The application uses the `googletrans` library for translation.

## Features

- Translate English sentences to Hindi.
- Practice vocabulary with common English-Hindi word pairs.
- Take quizzes to test your knowledge of Hindi vocabulary.

## Requirements

- Python 3.x
- `googletrans` library

## Installation

1. Clone the repository or download the code files.
2. Install the required library using pip:

   ```bash
   pip install googletrans==4.0.0-rc1
Usage
Run the program:
python your_script_name.py

Follow the on-screen menu to choose an option:
1: Translate English to Hindi
2: Practice Vocabulary
3: Take a Quiz
4: Exit
Example
Translate English to Hindi: Enter a sentence like "Hello, how are you?" and receive the Hindi translation.
Practice Vocabulary: View a list of common words and their Hindi translations.
Take a Quiz: Answer questions about Hindi translations of random English words.
Code Overview
Translation Function
The translate_to_hindi function translates a given English text to Hindi using the googletrans library.

Vocabulary Practice
The practice_vocabulary function displays a list of English words along with their Hindi translations.

Quiz Function
The quiz_user function randomly selects an English word and prompts the user to provide its Hindi translation.

Main Menu
The main_menu function provides a user interface for selecting different functionalities of the application.
